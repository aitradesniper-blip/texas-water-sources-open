Review date: October 20, 2026 UTC.

The selected private frontend's local refs, fetched GitHub branches, two tags and full reachable history were inventoried (158 reachable commits, 115 refs, two tags). A redacted Gitleaks 8.30.1 scan covered the reachable history. The scan produced 98 generic-key heuristic matches. Heuristic matches occurred in contract fixtures and meeting-record projections; no flagged corpus or fixture is included in this snapshot. The scan is a detection aid, not a guarantee that every credential or private detail can be detected.

A clean repository was chosen to keep historical operational notes, non-public provenance, author contact metadata and separately governed records private. The private repositories retain their history. The other water-data and commercial repositories are not included or relicensed.

The public allowlist contains original application and library code, code utilities, selected build configuration and a new independent starter. Data directories, contract payloads, complete official source documents, private research notes, screenshots, raster assets, deployment account IDs and history are excluded. Code does retain public source links and public-facing research language. Existing dependency notices remain in dependencies; no vendored dependency code is published.

The production reference source begins with the deployed navigation-fix lineage. The public starter needs no production data, credentials or service account. `source/` includes data-dependent modules as reusable implementation reference; it cannot reproduce the complete production site without separately supplied, rights-reviewed data and assets.

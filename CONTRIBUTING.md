# Contributing

1. Open an issue describing the reader problem and expected behavior. For factual corrections, link the primary source, relevant page/section, source date and date checked.
2. Make a focused branch. Preserve working public URLs and keep requests, recommendations, approvals, completed work and actual pumping distinct.
3. Run `npm ci`, `npm test` and `npm run build`. Check narrow mobile widths, keyboard focus, readable labels and destination links for changed UI.
4. Submit a pull request with the before/after behavior and actual checks. A demo link is helpful; screenshots must not expose private property or account information.

Do not add secrets, raw documents/OCR, personal property records, new tracking services or paid integrations. Do not claim statewide coverage, current funding, eligibility, ownership, water quality or well failure from incomplete evidence. Obtain permission before contributing third-party assets. Preserve all existing notices. Contributions to original code are under this repository's MIT license.

Report a suspected credential leak privately through GitHub's private vulnerability reporting if enabled. Do not paste credential values into issues. If no private reporting channel is available, open a minimal issue asking for one without sensitive details.

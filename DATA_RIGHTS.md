# Code license and data boundaries

The MIT license covers Texas Water Sources original application code and original documentation. It does not relicense agency or district documents, quoted source text, data packages, logos, maps, third-party dependencies, or third-party notices. Original rights and terms remain with their owners. Public accessibility is not a redistribution license.

The public code snapshot excludes the meeting-record corpora, original PDFs/HTML/OCR, managed inputs, contract fixtures, private provenance, operational notes and deployment account configuration. It includes links to official sources, not copies of complete source documents. The live site's published data is a separate, date-bounded research product; its availability does not grant an MIT license to third-party content.

Use official links and applicable agency terms to assess a proposed data use. Preserve citations, source dates and qualifications. Request permission where required. Do not commit raw customer addresses, precise private property details, credentials or private review notes. No source linked by this project is guaranteed complete, current or conclusive about a property.

Dependencies are obtained through npm and retain their own licenses. No dependency implementation is vendored in the public snapshot. Existing third-party copyright and license notices must be retained.
